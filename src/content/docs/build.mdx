Tell the Studio what you're building. It picks a small stack of vetted tools —
nothing owned by Meta, OpenAI, or xAI — then hands you everything an AI agent
needs to start: the project's rules (a **constitution**), the plan (a **spec**),
a ready-to-paste **prompt**, and a **starter repo you can download**, wired to
the same checks that run in CI.
